Správa webu

Katalog, texty a fotky webu Charm of Flowers. Uložené změny se na webu projeví do 1–2 minut.

Панель управления: каталог, все тексты сайта и фото. Токен выдаёт Vorthys — вкладка «Nápověda».

Bez klíče jde vše prohlížet, ale ne ukládat. Без ключа — только просмотр.

Příležitosti (čipy filtru)

Nová příležitost se hned nabídne u každé kytice. Новые «поводы» сразу станут фильтрами.

Kytice

Klikněte na řádek pro úpravy. Šipkami měníte pořadí, „skrýt" schová kytici mimo sezónu (nesmaže ji).

Každé pole má dvě verze: CZ česky a UA ukrajinsky. Prázdné pole = použije se původní text. Пустое поле — останется исходный текст.

Nahrát novou fotku

Fotka se sama zmenší a převede do správných formátů (JPG + WebP). Pak ji vyberete u kytice v záložce Katalog.

Jak panel funguje

Panel ukládá změny přímo do webu. Po „Uložit změny" se web sám přegeneruje — do minuty dvou jsou úpravy vidět. Nic se nedá nenávratně rozbít: každá změna se dá vrátit (napište Vorthysovi).

Přístupový klíč (token)

Klíč vám předá Vorthys, nebo si ho vytvoříte na GitHubu: Settings → Developer settings → Fine-grained tokens → Generate new token — přístup jen k repozitáři vorthys/charmofflowers, oprávnění Contents: Read and write.

Běžné úkony

Nová kytice: Fotky → nahrát fotku → Katalog → Přidat kytici → vybrat fotku, vyplnit název a cenu → Uložit změny.
Kytice mimo sezónu: Katalog → rozkliknout → Viditelnost „skrýt".
Změna otevírací doby či cen: Texty webu → skupina Hero / Ceník.
Ukrajinská verze: každé pole má sloupec UA — vyplňte oba.

Kontakt

Cokoliv dalšího (telefon, adresa, nové sekce, doména): Vorthys — web studio, Plzeň.

Новый букет: «Fotky» → загрузить фото → «Katalog» → «+ Přidat kytici» → выбрать фото из списка, заполнить название и цену (обе колонки CZ и UA) → «Uložit změny» внизу. Скрыть сезонный букет: раскрыть его и «Viditelnost: skrýt». Часы работы и цены — вкладка «Texty webu».
